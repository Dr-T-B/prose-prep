# Stage 6 — Edge function audit

Findings only. Read-only. 2026-05-21.

## Headline

- **One HIGH bug found:** Context Block 7 (interpretive_tensions) is empty in every production marking run. The filter uses `level_tag IN ('strong','top_band')` but the table's actual `level_tag` values are `'A*'` (3 rows) and `'A/A*'` (11 rows). The system prompt always renders `(none)` for this block, so the model loses its L5 interpretive-tension reference. AO2 sophistication detection is silently degraded.
- **Two MEDIUM concerns:** rate-limit only counts successful inserts (a streaming failure does not consume quota); duplicated VALID_APP_ROUTES + EXAM_WARNING constants between server (`validation.ts`) and frontend (`EssayMarker.tsx`).
- **Otherwise the marker is solid:** all 7 data-injection blocks query correct columns (Block 7 is the only mismatch); SSE section names match frontend parser exactly; rate limit math is correct; QuoteDiagnostic shape enforced on producer side; model = `claude-opus-4-7`; max_tokens = 4000; secrets never leak to client; auth enforced before stream opens; defensive AO5 stripping + canonical examWarning re-enforcement.
- `apply-staged-change` is **not deployed** (Stage 1.3); reviewed for inputs/outputs/secrets/failure modes but not deeply audited.
